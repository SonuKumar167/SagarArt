# Sagar Art Website

A PHP + MySQL website built with HTML, CSS, Bootstrap, and jQuery.

## Features
- Dynamic public pages: Home, Services, About, Contact
- Dynamic service listing and individual service pages
- Admin login and content management for pages and services
- Bootstrap navigation with Services dropdown
- Footer with cookie notice

## Run locally
1. Start Apache and MySQL in XAMPP/WAMP.
2. Open the project folder in your browser using:
   - http://127.0.0.1:8000/
3. If needed, start a local PHP server from the project folder:
   - C:\xampp\php\php.exe -S 127.0.0.1:8000
